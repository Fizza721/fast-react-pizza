# 🍕 Fast React Pizza

A modern pizza ordering application built with React.js. Users can browse the menu, add pizzas to their cart, manage quantities, and place orders through a simple and interactive interface.

### 🛠️ Technologies Used

- React.js
- Redux Toolkit
- React Router
- Tailwind CSS
- JavaScript (ES6+)
- Vite

### ✨ Features

- Browse the pizza menu.
- Add and remove pizzas from the cart.
- Update item quantities.
- Calculate total prices.
- Place orders.
